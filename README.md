## 🏗️ Featured Projects

### 🏥 Medical Clinic Booking System
> A full-stack appointment scheduling platform built for a real medical practice — my primary portfolio project.

- 📅 **Jalali (Persian) Calendar** — custom-built with `date-fns-jalali`
- 🔐 **JWT Auth** with access & refresh token rotation, OTP/SMS login (Iran Payamak API)
- 👨‍⚕️ **Multi-role system** — Admin, Doctor, Patient panels
- ⚡ **Real-time slot management** with concurrency handling (compound unique indexes to prevent double-booking)
- 📊 **Admin dashboard** — doctor management, paginated searchable user tables, comment system, Recharts revenue analytics
- 🌙 **Dark/Light mode** with SSR theme persistence

**Stack:** `Next.js 14` `MongoDB` `Mongoose` `Tailwind CSS` `Zustand` `JWT`

### ✅ Todo List Application
> A full-stack task management app with a relational data model and strict end-to-end type safety.

- 🗂️ Many-to-many relationship between todos and lists via a junction table, supporting independent completion states per list
- 🛡️ Dual-layer Zod validation — separate schemas for client-side form input and Server Action validation
- 🇮🇷 Full Persian / RTL interface

**Stack:** `Next.js` `TypeScript` `Prisma` `PostgreSQL` `React Hook Form` `Zod`

## 🧱 Architecture & Code Organization

- ✔ **Feature-based structure** — code organized by domain/feature (e.g. `features/appointments`, `features/auth`) rather than by technical layer, so each feature owns its components, hooks, actions, and types
- ✔ Clean Code over clever code
- ✔ Design patterns that scale
- ✔ User experience first
- ✔ Ship fast, iterate often
